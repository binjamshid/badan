# Native Implementation Plan

## Chosen baseline

- iOS: SwiftUI app
- Android: Jetpack Compose app
- Shared repo-level contracts in `packages/`

## Why this phase exists

This phase turns the previous architecture scaffold into a real native starter so the team can begin implementation without prematurely overcommitting to a shared runtime.

## Phase 2 goals

- create native app shells
- define first-pass shared contracts
- define metric ontology seed
- define export schema seed
- define first vertical slice modules

## First vertical slice

1. App launch shell
2. Home summary screen
3. Metric detail screen
4. Quick export screen
5. Placeholder logging screen
