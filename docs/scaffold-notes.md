# Scaffold Notes

This scaffold is intentionally expandable.

## Why all three app folders exist

- `apps/ios` and `apps/android` support a native-first future.
- `apps/flutter` keeps a cross-platform evaluation path open.
- shared packages avoid early lock-in while preserving architecture clarity.
